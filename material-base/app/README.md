# Protótipo

Abra `prototype-singlefile.html` no navegador. O protótipo inclui o formulário de drenagem, escolha de rodovia e dispositivo, estimativa geométrica e carimbo fotográfico.

Na GO-110, a busca permite escolher as estruturas, entradas, transposições e trechos presentes nos PDFs; os itens do projeto preenchem a estaca/local e mostram a referência de projeto. Na GO-236, a lista oferece os mesmos tipos de dispositivo e deixa o local para preenchimento manual, como combinado.

O logotipo Strata/Basitec aparece na tela inicial e nos relatórios. As fotos carimbadas são baixadas como arquivos separados. Os registros continuam locais neste navegador e ainda não sincronizam entre aparelhos.

Os dados estruturados e as páginas fonte da GO-110 estão em `../data/processed/projects/GO110/`. Veja `../data/processed/projects/GO110/README.md`.
